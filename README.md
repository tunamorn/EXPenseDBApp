# Checkpoint m04-finish — MyExpense

## แอปตอนนี้ทำอะไรได้แล้ว

- ตรวจข้อมูลก่อนบันทึก: เงินต้องมากกว่า 0 และไม่เกิน 500,000 / วันที่ต้องไม่เป็นอนาคต / ต้องเลือกหมวด
- ข้อความเตือนภาษาไทยขึ้นใต้ช่องที่กรอกผิด และช่องนั้นเปลี่ยนเป็นกรอบสีแดง
- แก้ไขและลบรายการได้
- กรองตามเดือนและหมวดได้ ยอดรวมเปลี่ยนตามตัวกรอง
- สรุปยอดตามหมวดพร้อมแถบสัดส่วน

**ยังทำไม่ได้:** ข้อมูลยังหายเมื่อ refresh เพราะยังไม่มีฐานข้อมูล

## วิธีใช้ checkpoint นี้

```bash
cd ~/projects
cp -r <โฟลเดอร์ที่แจก>/m04-finish myexpense
cd myexpense
npm install
npm run dev
```
